# 🚀 App Name: Hero-store

## 📖 Description

Productivity Tracker is a web app that let users to install various productive apps. So that they can complete tasks, track time, and monitor progress efficiently.  
It includes features like Showing trending apps,All the apps are available.Seeing each and every apps details.Adding specific apps to localStorage and delate from localStorage.

## 🛠️ Technologies Used

- **React.js** – Frontend UI library
- **Tailwind CSS** – Styling
- **Recharts** – For data visualization
- **Daisy Ul** - For nav and skeleton
- **Vite** – Build tool
